# Самостоятельная работа №3 "Определение целевой аудитории"

## 🗒️ Описание выполненной работы

В рамках данной самостоятельной работы было проведено исследование аудитории сервиса формирования здоровых привычек. Основные этапы работы

1. **Определение целевой аудитории:**
   * Выделен широкий спектр всех потенциальных пользователей.
   * Выделено **3 ключевых сегмента**, охватывающие большую часть потенциальных рользователей.

2. **Детальная характеристика сегментов:**
   * Проведен анализ сегментов по возрасту, уровню владения техникой, контексту использования, основным потребностям, основным проблемам, технической оценке, рискам тестирования и потребностям в данных. 

3. **Разработка портретов пользователей (User Personas):**
   * Сформированы детальные профили типичных представителей для каждого ключевого сегмента

4. **Формирование единого видения целевой аудитории**
   * Определены главные фокусы MVP
