# Данные для СР6

Папка для JSON, которые подхватывает сайт и модули Ангелины. БД не трогала — это на стороне Евгения и Андрея.

- `templates.json` — 12 шаблонов привычек (8 полезных, 4 замены). Форма «С чего хочется начать?», ФТ-1.1, ФТ-1.2, ФТ-1.3, ФТ-4.2.
- `daily_tips.json` — 28 карточек «Совет дня» для экрана «Сегодня», ФТ-5.5.
- `miss_reasons.json` — 6 причин пропуска и запасные ответы, если ИИ недоступен. ФТ-5.1, ФТ-5.2.
- `ai_prompts.json` — системные промпты для плана привычки и разбора пропуска. ФТ-1.5, ФТ-5.3, ФТ-5.4.
- `seed_demo.json` — тестовые профили Артёма, Марии и Игоря, история примерно за месяц (октябрь–ноябрь 2026). Для загрузки в БД, графиков и правил СР6/СР7.

Кодировка везде UTF-8.
