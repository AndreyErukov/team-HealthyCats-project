## Как повторить

### Маршруты и формы

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты создают отдельные экземпляры Flask, не требуют запущенного сервера и не меняют данные браузера.

Проверяются:

- успешный рендер страниц и локальных ассетов, порядок CSS/JS;
- хуки анимаций, native POST-формы, контракт HTML/Redirect для XHR без обхода CSRF;
- исходный счётчик 2/4 и идемпотентность отметки;
- отсутствие двойного засчитывания, отмена, минимум;
- обязательные поля, дни недели и план замены;
- диапазон дат, выключение напоминаний;
- блокировка отметок во время паузы;
- различие между выбором мягкого шага и фактом выполнения;
- сохранение и редактирование только внутри демо;
- отклонение неверного CSRF, включая Unicode-строку;
- экранирование пользовательского текста;
- демо-вход без сохранения пароля;
- сброс/выход и понятная 404;
- 30 корректных дат ноября в календаре;
- работа `PREVIEW_MODE` без cookies с подписанным токеном и сохранённой проверкой CSRF.

После добавления анимаций повторно пройдены 55 тестов, браузерный smoke-прогон (224 сочетания), отдельный motion-прогон и аудит axe. Логотип, Nunito, тема/шрифт и прежние сценарии сохранены. Визуально просмотрены спокойный и промежуточный кадры главной страницы, а также мобильное сообщение о сетевой ошибке.

### Браузер

Терминал 1:

```bash
python app.py
```

Терминал 2:

```bash
python -m playwright install chromium
python tests/smoke_browser.py
python tests/motion_browser.py
```

При необходимости Linux-библиотек: `python -m playwright install-deps chromium`.

`BASE_URL` позволяет проверить другой адрес. `SCREENSHOTS=1` сохраняет два контрольных скриншота в `tests/screenshots/` (эта папка не предназначена для коммита).

### Особенности motion-теста

- Проверяет не только конечную ширину шкалы: останавливает настоящую WAAPI-анимацию и проверяет промежуточный кадр.
- Удерживает ответ, чтобы убедиться, что до подтверждения сервера счётчик не увеличен; пять повторных submit дают один POST.
- Проверяет, что ошибка и тайм-аут не приводят к автоматическому повторному запросу или фиктивному выполнению.
- Проверяет паузу, включённую в другой вкладке, быстрые переключения и возврат фокуса после закрытия уведомления/диалога.
- Проверка без cookies требует `PREVIEW_MODE=1`: `PREVIEW_MODE=1 python app.py` в macOS/Linux или `$env:PREVIEW_MODE="1"; python app.py` в PowerShell. Без этого режима отдельный сценарий помечается `SKIP`.
- Cookie-free браузерный тест проверяет отсутствие cookies в запросах и правильную работу подписанных URL/полей, но не воспроизводит все политики сторонних iframe. Это не замена ручному тесту в браузере пользователя.

### Дополнительный аудит доступности

```bash
python tests/audit_accessibility.py
```

Аудит ждёт завершения входных анимаций: случайный полупрозрачный кадр не выдаётся за готовое состояние интерфейса. Промежуточные кадры не являются частью этого набора проверок контраста.

Тест отдельно скачивает axe-core 4.10.3 с CDN, внедряет его только в тестовый браузер и проверяет выбранные наборы правил. В сайт эта библиотека не встроена; runtime фронтенда не зависит от CDN.

## Ручной чек-лист перед защитой

1. Открыть `/today` в новой демо-сессии: четыре уникальные задачи, 2 выполнены.
2. Отметить фокус: без перезагрузки появляется галочка, счётчик 3/4, шкала плавно заполняется. Отмена плавно уменьшает её.
3. Выполнить минимум прогулки: 4/4; отменить её отметку.
4. На поддержке выбрать причину; убедиться, что выбирается только одна.
5. Отменить отметку фокуса, выбрать мягкий шаг: счётчик **не** должен расти до выполнения.
6. Раскрыть ИИ-разбор: видна подпись «Готовый пример · не ответ нейросети».
7. На «Привычках» проверить все три категории и открыть редактирование нужной карточки.
8. Создать привычку из шаблона; поменять дни и минимум; сохранить.
9. Убрать все дни: форма должна попросить выбрать хотя бы один.
10. Включить тёмную тему и крупный текст, перейти на другую страницу, обновить браузер.
11. Открыть расписание: дата окончания раньше начала не должна приниматься.
12. Применить предложение убрать пятницу; убедиться, что надо отдельно нажать «Сохранить».
13. Включить паузу: кнопки отметок на главной заблокированы. Возобновить план.
14. На статистике выбрать день мышью, затем перейти стрелкой на соседний.
15. На телефоне открыть меню, закрыть Esc/крестиком, проверить доступность всех разделов.
16. В настройках раскрыть «О демоверсии» и сбросить данные.
17. Открыть вход, переключить регистрацию, использовать **только тестовые** значения.
18. Включить системное «уменьшение движения»: кнопки и отметки работают без анимаций.
19. В DevTools включить Offline и попытаться отметить задачу: появляется сообщение, счётчик не растёт. Вернуть сеть и обновить страницу перед проверкой.
20. На телефоне отметить задачу в середине страницы: нет скачка к её началу; при работе клавиатурой фокус не теряется.

## Что ещё не проверялось / не реализовано

- Реальные Firefox, Safari, iOS/Android и ручной прогон со скринридерами.
- Полный аудит WCAG 2.2, тестирование всех динамических состояний axe и пользовательские исследования.
- Поведение настоящей БД, многопользовательская нагрузка и восстановление данных.
- Корректность расчёта серий, текущего периода дня, общей статистики и реальной автоматической паузы.
- Авторизация, SMTP/push, LLM API и защита production-инфраструктуры.

Не путать успешный фронтенд smoke-тест с готовностью всего продукта к публикации.
