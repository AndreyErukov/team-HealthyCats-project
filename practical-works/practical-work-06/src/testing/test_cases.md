# Тест-кейсы проекта «бережно» (СР6)

**Исполнитель:** Шибаршина Д.В.  
**Ветка:** `feature/testing`  
**Стенд:** http://127.0.0.1:5000 (`practical-works/practical-work-06/src/app.py`)  
**Основа:** 21 ФТ из `practical-work-04/report.md` + 8 граничных случаев (ЕС-1...ЕС-8).

**Статусы:**
* **Пройдено (стенд)** — проверено на текущем стенде (pytest или прогон маршрутов);
* **Не пройдено (BUG-XX)** — найдено расхождение, оформлено в GitHub Issues;
* **Проверить вручную** — нужен глаз в браузере или DevTools;
* **Ожидает сборки** — зависит от БД, алгоритмов или авторизации (на стенде их нет).

> На стенде нет БД, авторизации, LLM и расчёта серий: данные живут в памяти процесса. Поэтому кейсы про сохранность, пользователей и ИИ ждут сборки.
